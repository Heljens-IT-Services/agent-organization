# Dependabot-Leitplanke

[MUST_IF] Ein Repository npm-, NuGet-, Docker-, Docker-Compose- oder GitHub-Actions-Abhängigkeiten nutzt, muss `.github/dependabot.yml` diese Quellen abdecken.

[MUST] Jeder `updates`-Eintrag benötigt einen sinnvollen Zeitplan, `Europe/Berlin` und ein `open-pull-requests-limit`.

[OPTIONAL] Gruppen, Cooldowns sowie die Trennung von Major-Updates sind nach Bedarf zu verwenden.
